# 関門2 検証結果:「作る・育てる・戦う」がMVPとして遊べるか

2026-10-06 実施。画面での動作確認に加えて、`scripts/train.ts`(画面なし)と `bots/player-journey.sh` で検証した。

## 結論

**通過。** 新しいキャラが、移動 → 追跡 → 生き残り → 押し合い(突進BOT → 標準BOT)の合格まで、**約8分半**の学習でたどり着けた(Node、14スレッド)。ブラウザ(Worker 8本)でも十数分の見込み。

ただし、そこに至るまでに次の3つの調整が必要だった。いずれも「学習が遅い」のではなく、課題やステージの側に問題があった。

| --- | --- | --- |

## 見つけた問題と調整

### 1. 生き残りの合格(レベル3で60秒)がほぼ不可能だった

- 当初はレベル3をバトルと同じ崩落ペースにしていた。このペースでは、60秒時点で安全円の中の安全なタイルが平均14枚しか残らない。
- 手書きの回避ルール(穴と危険タイルを避けて安全円の中を歩き続ける)でも、60秒生き残れたのは 5/16 だけだった。
- **調整**:レベル1〜5のペースを 0.4・0.5・0.6・0.8・1.0 倍にした(レベル5 = バトル)。合格はレベル3(0.6倍)。

### 2. タイルの境目に体が引っかかっていた

- 腹ばいで進むキャラ(サンプル crawler)が、平地では進めるのに、タイルの上ではほとんど前に進めなかった(10秒で前進 -0.4m)。
- 原因:タイルごとに別のコライダー(凸包)だったため、境目の辺に体が引っかかる「ゴースト衝突」が起きていた。
- **調整**:残っているタイルの上面と穴の縁の壁を、頂点を共有した1つの三角形メッシュにまとめ、Rapier の `FIX_INTERNAL_EDGES` で境目を滑らかにした。タイルが崩れたらメッシュを作り直す。調整後は 10秒で +1.0m 進み、平地での動き(+2.1m)に近づいた。

### 3. 2体がほとんど出会わず、押し出しが起きなかった

- 「中心を挟んで3マス離れた位置」を「中心から3マスずつ」(2体の間は約6m)と解釈していたため、標準BOT同士の試合では一度も2m以内に近づかなかった。
- 脱落の原因の判定も、コア同士の距離(1.2m未満)で接触を見ていたため、体の長いキャラが押し合っても「自分で落ちた」と判定されていた。
- **調整**:2体の間を3マス(中心から1.5マスずつ)にし、接触の判定を2体のブロックの実際の接触にした。

試合は30秒前後で決着し、時間切れの引き分けはなかった。脱落の多くは崩落による自滅で、押し出しは2〜3割。

## 残った課題(今後の調整候補)

- **体型による差が大きい**:腹ばいのキャラ(crawler)は、その場で回ってしまう歩き方を覚えやすく、生き残りの合格に届かなかった(300世代)。一方で、試合では標準BOTに勝てることもある。体の組み方の差が出るのはゲームとして意図どおりだが、詰まったときのヒントがあるとよい。
- **標準BOTが少し弱い**:新しいキャラが押し合いを9世代で合格した。押し合い自体は面白くなっているが、合格の目標としてはもう少し強くてよい(`bots/make-standard-bot.sh` で押し合いを長く学習させる)。
- **押し出しが少ない**:弾力ブロックの反発や、押し合いの報酬の重みを上げると、ぶつかり合いが増える見込み。
- **運動脳は速さ1の指令でしか学習していない**:判断脳が出す「速さ」(0〜1)を運動脳が使いこなせていない。移動・追跡で速さを変える工夫が考えられる。
